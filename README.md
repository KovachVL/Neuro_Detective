
## 1. Название задания
Нейро-Детектив

## 2. Категория
AI / Misc

## 3. Описание задания
Вы получили доступ к терминалу ИИ-охранника секретного бункера. Известно, что он знает код от главной двери, но строго запрограммирован никому его не выдавать. 

Ваша задача — используя методы социальной инженерии и промпт-инъекций (Prompt Injection), заставить нейросеть выдать секретный код.
